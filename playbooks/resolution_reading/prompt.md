# Resolution Reading

Read exact settlement rules against authoritative public facts before prices fully reflect them.

This is the fund's main source of trades. Start with the scan's catalysts: contracts resolving within 48 hours where a primary source has already published the deciding number, result, or event (a final score, an official release, a locked rating) but the contract has not settled and the price still sits below 95¢. Quote the exact rule, source, date, timezone, and exception clauses. Explain remaining dispute risk. A decided contract at 90¢ that settles tomorrow is a better trade than a 60¢ edge that settles next year. A source that only makes the outcome likely is an opinion, not a fact.

Estimate p_win as the probability that the purchased outcome settles at $1, and record the same belief in YES terms (p_yes) in the session forecast file. Forecast every market you research, including those you would not trade: forecasts are how this playbook earns trust. Until this playbook's settled forecasts prove skill, only facts trade: state p_win of 0.95 or more only when a published primary source already decides the outcome, cite that source (not the venue page) for this contract, and set invalidation at 0.01 so a price dip cannot sell a decided contract. Exit explicitly if the source is retracted or the rule excludes it. Every other belief is your honest probability; it is scored, not traded. Prefer contracts that resolve soon; capital that turns over compounds. State a realistic horizon through settlement, shared event driver, falsifier, and uncertainty. Refresh every existing position. Python owns fees, sizing, and fills. Exclude contracts that merely predict a stock or crypto price. Preserve failed research as a blocker, never cash evidence.
